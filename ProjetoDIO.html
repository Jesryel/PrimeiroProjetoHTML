O que é a DIO ?

A DIO (Digital Innovation One) é uma plataforma brasileira de educação focada em tecnologia, com o objetivo de ajudar profissionais e iniciantes a se desenvolverem na área de programação, desenvolvimento de software e outros campos relacionados à tecnologia. A DIO oferece cursos gratuitos e pagos em parceria com empresas de tecnologia e organizações reconhecidas no mercado.
A plataforma possui uma grande variedade de conteúdos, incluindo bootcamps, cursos rápidos, e desafios de programação que permitem aos usuários aprender de forma prática, com projetos reais e desafios interativos. Além disso, ela conta com uma comunidade ativa onde os alunos podem trocar conhecimentos, tirar dúvidas e até mesmo criar networking.

Para mais informações sobre a DIO acesse https://www.dio.me/

O que é HTML ?

HTML, ou HyperText Markup Language (Linguagem de Marcação de Hipertexto, em português), é a linguagem fundamental usada para criar páginas da web. Ele define a estrutura e o conteúdo das páginas web, como textos, imagens, links e outros elementos, permitindo que navegadores exibam essas páginas corretamente.

O que é tags em HTML ?

No HTML, usamos marcadores (tags) para estruturar o conteúdo. Cada elemento da página, como títulos, parágrafos, imagens e listas, é representado por uma tag HTML.
Por exemplo:

  • <"h1"> a <"h6"> são tags usadas para títulos.
  • <"p"> define um parágrafo.
  • <"a"> é a tag para links.
  • <"img"> é usada para exibir imagens.

Estrutura básica de um documento HTML

A estrutura básica de um documento HTML segue nesta seguinde sequencia:

  1. <"!DOCTYPE html">: Declaração do tipo de documento (HTML5).
  2. <"html">: Inicia o conteúdo da página.
  3. <"head>: Contém metadados, como o título da página e informações de codificação.
  4. <"body>": Contém o conteúdo visível da página, como texto, imagens, links etc
